# 🧾 Credit Card Statement Parser

## 📌 Overview
This project extracts 5 key data points from credit card statement PDFs of 5 issuers:
- Chase
- Citi
- Bank of America
- American Express
- Capital One

## 📊 Data Extracted
- Card last 4 digits
- Card variant
- Billing cycle (start & end)
- Payment due date
- Total balance

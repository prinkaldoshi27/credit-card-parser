# 🧾 Credit Card Statement Parser

## 📌 Overview

This project is a **Python Flask web application** designed to automatically parse and extract critical financial metadata from uploaded credit card statement PDFs. It leverages the **`pdfplumber`** library for robust text extraction and **regular expressions** for precise data identification.

The application supports specific credit card issuers and extracts **5 key data points**:

  * **Supported Issuers**: Bank of America, Kotak, ICICI Bank, One/South Indian Bank, and Chase.
  * **Extracted Data Points**:
    1.  Issuer Detected.
    2.  Card Last 4 Digits.
    3.  Total Balance.
    4.  Payment Due Date.
    5.  Minimum Payment Due.

-----

## 💻 Technical Stack

| Component | Technology/Library | Purpose |
| :--- | :--- | :--- |
| **Backend Framework** | Python / Flask | Handles routing, file upload, and application logic. |
| **PDF Extraction** | `pdfplumber` | Used for reliable extraction of text content from the PDF files. |
| **Data Parsing** | Regular Expressions (`re` module) | Employs sophisticated, bank-specific patterns for data extraction. |
| **Frontend Styling** | Bootstrap 5 (via CDN) | Provides a modern, responsive user interface. |

## 🛠️ Setup and Installation

### Prerequisites

You must have **Python 3.x** installed.

### Installation Steps

1.  **Obtain Files**: Ensure you have the project files (`app.py`, `upload.html`, `results.html`).

2.  **Install Required Libraries**: Use `pip` to install the dependencies:

    ```bash
    pip install Flask pdfplumber
    ```

### Running the Application

1.  Execute the main application file from your project directory:

    ```bash
    python app.py
    ```

2.  Open your web browser and navigate to the local server address provided in the console (e.g., `http://127.0.0.1:5000/`).

-----

## 🔒 File Handling and Security

The application incorporates robust measures to ensure the integrity and security of uploaded documents:

  * **File Type Restriction**: Only PDF files are allowed (`ALLOWED_EXTENSIONS = {'pdf'}`).
  * **Size Limit**: The upload is strictly limited to **5 MB** (`MAX_CONTENT_LENGTH = 5 * 1024 * 1024`).
  * **Temporary Deletion**: Files are saved temporarily with a unique name generated by `uuid.uuid4()`. They are explicitly removed using `os.remove(file_path)` after processing in a `finally` block, ensuring immediate deletion even if an exception occurs during extraction.

-----

## 💡 Extending Bank Support

To add support for a new credit card issuer, you need to modify two core functions in **`app.py`**:

1.  **`determine_issuer(pdf_path)`**:

      * Add a new conditional block (`if`/`elif`) to identify unique text or URL patterns associated with the new bank within the PDF's content.

2.  **`extract_metadata(text, issuer)`**:

      * Create a dedicated `elif issuer == "NewBankName":` block.
      * Write specific Regular Expressions to accurately locate the four required data points (card number, balances, and date) based on the new statement's formatting.
      * Ensure all monetary values are passed through the `clean_amount()` utility function.
